# ИМПУЛЬС — интерактивный прототип

Демонстрационный адаптивный PWA-каркас образовательной платформы по физике для 7–11 классов.

## Состав
- `index.html` — структура приложения
- `styles.css` — фирменное оформление и адаптивная сетка
- `app.js` — навигация и демонстрационные интерактивности
- `manifest.webmanifest` — параметры установки PWA
- `sw.js` — базовое кэширование оболочки для офлайн-запуска
- `icon.svg` — черновая иконка приложения

## Запуск
Для локальной проверки запустите любой статический HTTP-сервер в папке проекта. Например, `python -m http.server 8000`, затем откройте `http://localhost:8000`.

Для публикации на GitHub Pages загрузите содержимое папки в репозиторий и включите Pages. PWA и Service Worker требуют HTTPS (GitHub Pages его предоставляет).

## Важно
Это функциональный дизайн-прототип, а не готовый учебный курс. Перечни тем предварительные; перед наполнением необходимо сверить их с действующими федеральными и школьными рабочими программами. Часть разделов содержит демонстрационные материалы. Для полноценного офлайн-режима нужно отдельно реализовать кэширование учебных изображений, лабораторных моделей и данных, а также тестировать обновление кэша на реальных устройствах.
